# Cost Guard

Cost Guard is a local Web dashboard for OpenCode. Follow live prompts and
sessions, reference model costs, Token Mix, context and account quotas.
It runs a local Web server and opens the dashboard in your browser.

## Windows

Start [windows/Cost-Guard-Web.cmd](windows/Cost-Guard-Web.cmd).

## macOS

Start [macos/Cost-Guard-Web.command](macos/Cost-Guard-Web.command).

Requires Python 3.11+ and OpenCode. Use the tray/menu **Exit Cost Guard**
action to stop the application.

## Legacy

Terminal report and Watch launchers remain available in `windows/Legacy`
and `macos/Legacy`.
