# Cost Guard

Starts a local Web server and opens your browser for OpenCode sessions, prompts,
pricing, Token Mix and quotas.

## Requirements

Requires Python 3.11+ and OpenCode on Windows and macOS.
Use the tray/menu **Exit Cost Guard** action to stop the application.
Keep `cache/` when updating or moving a stopped installation.

While connected, Web prioritizes the visible page and warms others slowly, including all four
Accounts CCost chart periods. Watch and Mini update independently; session details load on demand.

## Windows

Start [windows/Cost-Guard-Web.cmd](windows/Cost-Guard-Web.cmd).

## macOS

Start [macos/Cost-Guard-Web.command](macos/Cost-Guard-Web.command).

## Legacy

Terminal reports and Watch: `windows/Legacy` and `macos/Legacy`.
