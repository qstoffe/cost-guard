# Cost Guard version history

## v80.56 — 2026-10-15

- Watch quotas use an independent account-only scheduler, start-anchored 30-second healthy refreshes and one bounded lane per configured adapter. Provider attempts have a 20-second Watch deadline; blocked lanes cannot starve other providers or spawn replacements. Normal reports retain four workers and their existing wait budget.
- Transient failures, including after success, receive at most three 5/10/20-second recovery retries before 60-second degraded checks; durable auth/capability/format failures get no fast retries. Credential-backed retries pin failed accounts without reobserving healthy neighbors. Publication uses cached local usage, never source hydration; unchanged provider responses are new observations, cached replays are not.
- Observations older than 60 seconds are visibly stale and last-known values expire after five minutes even without another completion; resume never extends that bound. Privacy-allowlisted numeric evidence distinguishes attempts, completion, observation, publication, scheduling/worker delay and displayed freshness. Deterministic idle/active rendering tests demonstrate the 60-second end-to-end objective for whole-provider acquisition up to 20 seconds and responsive local scheduling/rendering; upstream propagation and external outages remain outside the guarantee.

## v80.55 — 2026-10-15

- Global Watch keeps historical session blocks above active/recent blocks in one unchanged six-column table, with one border-style divider only when both groups exist. Active/recent headers and ordering use latest prompt/compaction start; history uses the latest existing terminal/completion evidence, falling back to event start when an end is unavailable. Session ID breaks ties.
- Sessions remain active through the existing finite completion/abort highlight, then move to history on idle wakes using the event end rather than observation/expiry time. New activity moves the whole block back; persistent error markers do not keep history active. Row selection, Earlier accounting, scoped Watch, colors, subtotals, warnings, activity/Skills rows and quotas are preserved.

## v80.54 — 2026-10-15

- Behavior-neutral cleanup: prompt-block projection (one-shot detail reports and every changed Watch root) indexes model replies once for effort labels instead of rescanning all session messages per prompt, and builds one shared context-history index instead of two. A synthetic 2,000-prompt root fell from 0.76 s to 0.26 s (1,000: 0.25 s to 0.12 s) with identical projections. Watch rendering drops an unused column indirection and the code map no longer mentions local product ZIPs.

## v80.53 — 2026-10-15

- Watch's CCost summary becomes `CCost · Watch: <run> · Today: <day> · Deleted sessions before Watch start are not included in Today`. From local midnight until 03:00 in the configured timezone, `Today` is replaced by the current local date `YYYY-MM-DD`; status wakes redraw both transitions while idle without source or account work. Narrow terminals move only the explanation to an indented continuation line. CCost values, rounding, `?`/`N/A` and Today retention are unchanged.

## v80.52 — 2026-10-14

- Separate actual request usage from continuing context estimates. V2 active-history evidence keeps temporary outgoing-context reductions from replacing the session anchor; verified history changes re-establish the baseline, and unproven decreases remain unknown. Usage, Calls, Token Mix, CCost and billing remain request-based.
- V2 snapshots retain the documented active-context message IDs and include revert/fork metadata in source revision gating. Completed compaction still owns its shrink; inactive reverted rows do not become the continuing anchor.
- Keep Watch's `Δctx → Next Ictx` content width fixed at 20 with aligned delta/arrow/Next fields and a reserved warning-marker slot through `*99`; warning changes no longer widen the 119-character table.

- Added compact available-model reports, full-catalog/session/date modes, request-proven effort labels, independent colors and amber Next-Ictx warnings. Watch retains session grouping, aligned tool/failure/running/TODO status, run/session CCost totals, bounded quota recovery, fixed geometry and terminal cleanup.

- Earlier PowerShell generations established causal attribution, context estimation, pricing-cache safety, configurable colors and low-idle-cost Watch constraints. v77.0 remains the historical behavioral reference for the Python rewrite.
