# FR000651 — Exact OpenCode model-ID flow and recovery plan

**Research-only companion, 2026-11-09.** This documents public source code, **not** a successful read of the owner's workstation, old Claude SDK transcript or OpenCode database. Previous On Hold was explicitly revoked by the owner. Do not claim that any particular older alias has already been resolved.

## 1. Verified baseline and why Desktop differs from historical truth

Source inspected at OpenCode **v2.2.6** commit **dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06**, and current 2026-11-09 development commit **09deb091c513e07292dcb31bf418c9824d94b215**. The critical source path agrees on both. The prior investigator saw a running service reporting v2.2.6; reported version alone does not prove the local executable's precise build hash.

1. [Claude stream converter](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/language-model/convert-claude-stream.ts) handles top-level SDK **stream_event.message_start** and emits **{type:"response-metadata", id:messageID, modelId:event.message.model}**. This is the actual response-model field; parent-tool-use streams are separately gated.
2. [OpenCode AI-SDK bridge](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/aisdk.ts) handles **case "response-metadata"** by **Effect.succeed([])** in streamPartEvents. **This is the exact loss boundary.** No durable LLM event is emitted for this model field.
3. [Runner step](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/session/runner/step.ts) calls createLLMEventPublisher with **input.model.ref**, i.e. the selected alias. [Publisher](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/session/runner/publish-llm-event.ts) records selected model in Step.Started.
4. [Message updater](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/session/message-updater.ts) uses Step.Started's model for assistant.model. Step.Ended stores usage, cost, finish/native metadata, but cannot recover dropped response-metadata. [Session message schema](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/schema/src/session-message.ts) has model: Model.Ref and optional native, no separate executed-model identity. [Session transfer](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/session/transfer.ts) exports settled session messages, not native Claude stream history.
5. [Desktop modelItems](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/session-ui/src/message/message-content.tsx) displays provider.all.get(model.providerID).models[model.id].name (fallback model.id). [Claude provider](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/provider.ts) stores mutable SDK ModelInfo **value/displayName/resolvedModel** for its *current* catalog and current pricing. Consequently **a historical claude-agent/sonnet may appear as today's Sonnet 5.5 without proof of the release that answered that old request**.

**Do not implement a catalog-label override as the FR fix.** It would repeat the prior false Sonnet 4 attribution with another guessed model.

## 2. New high-priority historical recovery hypothesis: exact SDK transcript join

This is the strongest additional avenue found after the hold and must be exercised against an authorized real session. Importantly, OpenCode itself already uses the official SDK transcript API.

- [Plugin ID](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/index.ts): **opencode.provider.claude-agent**. It passes its namespaced storage to ClaudeSessions.
- [Plugin session record](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/sync/record.ts): stored logical key **sessions/<exact OpenCode session ID>**, with **claudeSessionID**, optional history list of **hash + claudeMessageID**, interrupted flag.
- [ClaudeSessions turn and settlement](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/claude/sessions.ts): when a top-level SDK assistant message completes, records **messageID = message.uuid** and persists Checkpoints.build reply on a settled persisted session.
- [Checkpoints.build](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/sync/checkpoints.ts): appends **a reply checkpoint with the actual Claude assistant UUID** for a completed reply and carries earlier source-qualified checkpoint UUIDs forward when the prompt fingerprint still matches. Can also retain tool-message UUIDs. Interrupted requests, dropped history, compaction, forks or agent side runs may leave gaps or remap UUIDs.
- [ClaudeFork.create](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/claude/fork.ts) **already calls getSessionMessages(sessionID)**, finds transcript entries by UUID, and checks copied message equality. Thus the SDK transcript **read** accessor is used by upstream. **Do not call forkSession or deleteSession for investigation**: they mutate sessions.
- [Claude stream converter](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/language-model/convert-claude-stream.ts) attaches {sessionID, messageID: assistant.uuid} provider-native metadata to some tool calls/nonstreamed text. That is another **possible exact join** on rows where it survives, not a general guaranteed mapping for streamed text.

The official Claude SDK **getSessionMessages(sessionId, {dir, limit, offset})** reads historical transcript entries (UUID/type/message). Claude assistant message shapes include **message.model**; OpenCode's own Claude SDK recordings contain concrete message.message.model values. See [official session-browser example](https://platform.claude.com/cookbook/claude-agent-sdk-05-building-a-session-browser), [SDK changelog](https://github.com/anthropics/claude-agent-sdk-typescript/blob/main/CHANGELOG.md), and [upstream usage](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/provider/claude-agent/claude/fork.ts). **This proves a supported read function exists, not that the desired historical message/model/UUID is still retained on the user's installation.** The SDK has had transcript-flush and fork-ID fixes; check the installed version and settled snapshot before judging a missing response.

### Exact OpenCode KV locator is derivable (read-only probe only)

[plugin/host.ts::storage](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/plugin/host.ts) namespaces plugin keys as **plugin:** + each UTF-16 code unit of plugin ID formatted as 4 lowercase hex digits + **:**. [KV SQL schema](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/kv/sql.ts) has exact **kv.key** and JSON-valued **kv.value**. For this plugin, the verified key prefix is:

~~~text
plugin:006f00700065006e0063006f00640065002e00700072006f00760069006400650072002e0063006c0061007500640065002d006100670065006e0074:
~~~

Add **sessions/<exact OpenCode V2 session ID>** to get the candidate key. **Never scan all plugin keys or dump KV JSON.** Only the owner's exact session ID is authorized for a targeted read-only local SQLite snapshot or plugin-owned getter. Store/report merely presence, hashed/sanitized Claude session/UUID linkage and model IDs; no unrelated transcript, prompt text, credentials or secret keys. Prefer a narrow provider-owned **OpenCode authenticated read-only API** for ongoing integration rather than depending permanently on the internal KV layout.

### Joining is the real technical requirement

A Claude model can be used for a historical OpenCode assistant **only** when a session-qualified checkpoint/native reply UUID maps unambiguously to the official SDK transcript entry, and that entry exposes a trustworthy executed **message.model**. Verify physical step/assistant attribution, true provider route, source instance, revision, tool/fallback/compaction ownership and usage scope. Never join using just mutable current catalog, proximity of timestamps, model family or arbitrary visible text. If a Claude transcript or exact UUID is gone, leave that particular old response **version unverified** and proceed with remaining pathways rather than guess.

## 3. What Cost Guard can and cannot get today

[Cost Guard opencode_v2_wire.py::fetch_messages](https://github.com/qstoffe/cost-guard/blob/main/src/sources/opencode_v2_wire.py) reads **GET /api/session/<sessionID>/message** (with backward-compatible fallbacks). The same module maps saved assistant.model provider/id/variant; providerState.responseId when present is a **candidate** correlation, not guaranteed executed-model evidence. [opencode_v2_normalization.py](https://github.com/qstoffe/cost-guard/blob/main/src/sources/opencode_v2_normalization.py) normalizes that model to canonical per-invocation ModelRef and attaches it to physical step usage. It does **not** acquire a discarded response-metadata.modelId from the ordinary V2 history route.

**Missing via the ordinary API:** per-response **executed model ID**, tied to exact Claude message/step, plus any corresponding checkpoint-to-SDK transcript lookup evidence. OpenCode has candidate extra local metadata in plugin KV and the official Claude SDK's own transcript, but the ordinary V2 session history/export does not currently demonstrate exposure of that join.

## 4. Mandatory implementation sequence and tests

1. **P0 real single-session probe, no inference:** obtain the exact owner-authorized V2 session ID with the alias symptom. Read that session's ordinary V2 assistant/part metadata only; verify runtime version and correlation IDs. Query only the matching plugin KV key via a sanctioned read-only snapshot or provider-owned method. Fetch **only that Claude session** using official SDK getSessionMessages, with its actual directory and finite pagination. Reduce content to assistant UUID/model/source metadata; do not copy private text into the report.
2. **Prove exact mapping:** use saved claudeMessageID checkpoint or preserved native tool message UUID; verify the model on the **same executed response**, not a neighboring reply. Test old Sonnet 4 and 5.5 across two requests in one root, exact tool continuations, forked remap, wrong SDK session, missing transcript, interrupted reply and parallel subagents. Keep failed joins unknown.
3. **P1 upstream persistence:** [aisdk.ts::streamPartEvents](https://github.com/anomalyco/opencode/blob/dc2ffcf8bf26f9e669b6aa22b95f50e12be15e06/packages/core/src/aisdk.ts) must preserve **response-metadata.modelId + response ID** as a typed, safe LLM event. Propagate through per-response step ownership, durable events, message schema/updater/projector/transfer and authenticated V2 session API. Preserve **selected alias and executed response model separately**. One step might contain multiple physical responses/fallbacks; do not overwrite a step-wide field with an unqualified last model. Emit/retain correct evidence for retries, tool boundaries, failure and nested agents. Write source-level tests and a tightly scoped upstream PR/issue if needed; **no live paid replay** is necessary for synthetic proof.
4. **P2 Cost Guard integration:** import only verified source-qualified response identity, preserving alias/provider/variant. Price via existing exact model/cost catalog, not from current names. Extend existing MODEL_IDENTITY_SEMANTICS/versioned cache dependencies to repair previously affected session/analysis/history, Watch/Mini, CLI, Token Mix, AI Stats, Comparisons and per-root costs without global raw-history deletion. Test cold, warm, restart, updated source/catalog and multiple model releases.
5. **Acceptance:** real old-session recovery where source evidence exists, truthful remaining unverified old rows where no evidence can exist, and proven durable future responses with per-request fidelity. Publish PASS/FAIL/NOT RUN, source versions and synthetic fixtures. The owner revokes former On Hold. **No automatic hold, priority demotion or completed status without a new explicit owner decision.** If one hypothesis fails, preserve a concrete failure fixture and proceed to the next. Work iteratively, not via unbounded retry loops or fabricated evidence.
