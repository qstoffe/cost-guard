## Reported regression and non-negotiable result

In **Cost Guard**, Claude Agent-backed prompts/sessions that the owner sees in **OpenCode Desktop as “Claude Sonnet 5.5”** formerly displayed the false concrete model **Claude Sonnet 4**. **Completed FR000629** (v80.218) fixed that false assignment by showing **Claude Sonnet (version unverified)** and keeping reference CCost unresolved for alias-only requests. That is **safer than a wrong version, but it is not the desired final behavior**.

The owner wants the actual model release when it can be established; **when it cannot, the owner explicitly approves the same current alias→model-name lookup used by OpenCode Desktop, even if it can be historically wrong**. This is an accepted pragmatic fallback for **both displayed model identity and reference CCost**. A successful, truthful implementation of that fallback *does* satisfy the revised FR's user-visible behavior; it must never be represented internally as verified execution.

**Target:** A Claude Agent invocation genuinely executed with **Claude Sonnet 5.5** should show **Claude Sonnet 5.5** (with its true provider/variant/effort preserved), including in **Web Sessions catalog/detail, Full Watch/Mini Watch, CLI reports, model/group tooltips, Token Mix and other historical model-dependent views**, **when an actual request-time identity can be established**. Do not assume all aliases throughout history were 5.5; another prompt may genuinely be Sonnet 4, 4.5 or a later release. A prompt can have a different actual model than the session's current selection.

**This FR goes beyond the previous conservative unverified label:** first implement the owner-approved catalog-based Desktop parity fallback including prices; then investigate/recover verifiable per-request history where available, and preserve a path to an upstream durable response-model field. Do not block the useful fallback on missing historical SDK transcripts or upstream contributions. Any new On Hold decision or requirement change still requires fresh owner approval.
