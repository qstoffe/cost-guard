## Changes and decisions

- `instance_state.py` canonicalizes checkout identity, uses user-local private app data, protected inherited Windows owner DACLs / Unix modes, atomic records, and separate OS-held transition/lifetime locks. The child lifetime lock prevents duplicates even if the launcher crashes before readiness. Records bind nonce, PID and birth/image, loopback endpoint, startup schema/build, readiness timestamp and control authentication.
- `lifecycle.py` serializes deliberate same-build restarts, coalesces overlapping invocations, waits for authenticated shell/GUI readiness and separates browser failure from server failure. Detached spawn has private cwd, null standard streams, closed inherited handles and platform session/console flags. Missing native adapters fail closed, never icon-free background success.
- Graceful stop has a ten-second deadline. Force-stop revalidates a Windows kernel process handle or Linux pidfd. Unknown endpoints, corrupt records and ownership conflicts never authorize killing a process/port or starting a duplicate. Stale/reused PIDs are removed without contacting their replacements. macOS currently refuses unsafe forced termination when no atomic process handle exists; this is a safe explicit conflict, not a native success claim.
- `host.py` owns terminal/idempotent stop from menu, launcher, worker failure and source guard. Required native adapter run/close stay on the main thread; HTTP/jobs are elsewhere. Any returned/failed GUI stops the host. Worker death signals icon removal and propagates the original failure to the existing sanitized runtime reporter. Managed software artifacts and bounded allowlisted lifecycle logs remain outside Git. Finite report children monitor the exact multiprocessing parent sentinel, so a crashed/force-stopped host cannot orphan a blocked report scan.
- `change_guard.py` baselines relative membership, size and nanosecond mtime before normal serving, checking every five seconds. Runtime Python/assets/entries/manifests and Beta launcher trees are allowlisted; links are never traversed. Development/docs/cache/log/bytecode/environment/user-configuration writes are excluded. Transient stat errors retry honestly against the original baseline. Proven change is terminal `source_changed`, rejects new work and stops without browser acknowledgement. No updater/reload/restart, Git action or CLI termination is introduced.
- `/control/*` uses a private secret header and rejects browser Origin/Cookie; it never exposes that credential to the page. Browser sessions are instance-scoped; a new Open handoff preserves already authenticated same-instance tabs. `--foreground` is now explicit developer mode. Detailed adapter/API/recovery constraints are in [Web Beta](../../../../docs/web-beta.md).
